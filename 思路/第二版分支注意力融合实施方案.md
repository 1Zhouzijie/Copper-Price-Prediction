# 第二版模型实施方案：分支注意力融合

## 1. 第二版要解决的问题

第一版模型结构为：

```text
V1 = CNN(X_copper)
V2 = GAE(G_market)
V3 = GAE(G_demand)
V4 = GAE(G_supply)

V_final = concat(V1, V2, V3, V4)
prediction = MLP(V_final)
```

其中：

```text
V1：铜期货自身历史量价特征
V2：market 图嵌入特征
V3：demand 图嵌入特征
V4：supply 图嵌入特征
```

第一版采用简单拼接，优点是实现简单、结构稳定、适合作为基准模型。但是它也有一个明显问题：模型没有显式判断 `market`、`demand`、`supply` 三个图分支在不同样本下的重要性。

铜价在不同阶段的主导因素可能不同：

```text
宏观金融主导阶段：美元指数、利率、黄金、原油、权益市场更重要
需求预期主导阶段：AI 硬件、新能源车、电网设备、地产基建更重要
供给扰动主导阶段：矿企股票、交易所库存、注销仓单、运费更重要
```

因此，第二版模型希望解决的问题是：

```text
对于每一个交易日样本，模型能否自动判断 market、demand、supply 三个图分支谁更重要？
```

第二版的核心改动是：

```text
把 V2、V3、V4 的简单拼接，改为基于注意力机制的自适应加权融合。
```

## 2. 第二版总体结构

第二版保留第一版的 CNN 分支和 GCN-GAE 分支，不改变数据输入和损失函数。

整体结构为：

```text
CNN 分支：
X_t -> CNN1D -> V1

GAE 分支：
G_t^market -> GCN-GAE -> V2
G_t^demand -> GCN-GAE -> V3
G_t^supply -> GCN-GAE -> V4

分支注意力融合：
V1 引导 V2、V3、V4 的权重分配
V_graph = alpha_market * V2 + alpha_demand * V3 + alpha_supply * V4

预测层：
concat(V1, V_graph) -> MLP -> [low_return, high_return]
```

也可以写成：

```text
V1 = CNN(X_t)
V2 = GAE(G_t^market)
V3 = GAE(G_t^demand)
V4 = GAE(G_t^supply)

alpha_market, alpha_demand, alpha_supply = BranchAttention(V1, V2, V3, V4)

V_graph =
    alpha_market * V2
    + alpha_demand * V3
    + alpha_supply * V4

V_final = concat(V1, V_graph)

y_hat = MLP(V_final)
```

## 3. 为什么用 V1 引导注意力

这里建议使用 `V1` 作为注意力机制的查询向量。

原因是 `V1` 来自铜期货自身的历史量价矩阵，反映了铜价近期状态。例如：

```text
近期铜价大幅波动，且风险资产同步波动：
模型可能更关注 market 图。

近期铜价上行，同时 AI、新能源车、电网设备股票强势：
模型可能更关注 demand 图。

近期铜价上涨，同时库存快速下降、矿企股票强势：
模型可能更关注 supply 图。
```

因此，第二版的注意力逻辑不是静态地给三个图固定权重，而是：

```text
根据铜自身近期走势 V1，动态判断三个图分支的信息价值。
```

这使模型更符合铜价研究中的实际逻辑：

```text
铜价自身走势先反映市场状态；
然后模型根据该状态选择更应该相信宏观市场、需求端还是供给端信息。
```

## 4. 数学表达

### 4.1 输入向量

设：

```text
V1：CNN 输出的铜自身特征
V2：market 图输出的图嵌入
V3：demand 图输出的图嵌入
V4：supply 图输出的图嵌入
```

当前代码中的默认维度为：

```text
V1 ∈ R^64
V2 ∈ R^32
V3 ∈ R^32
V4 ∈ R^32
```

其中 GAE 图向量为 32 维，是因为：

```text
每个节点嵌入维度 = 16
图向量 = 铜节点嵌入 16 维 + 全图平均嵌入 16 维
所以每个图分支输出 = 32 维
```

### 4.2 查询、键和值

第二版采用类似 Query-Key-Value 的注意力结构。

将铜自身向量 `V1` 映射为查询向量：

```text
q = W_q V1
```

将三个图分支向量映射为键向量：

```text
k_market = W_k V2
k_demand = W_k V3
k_supply = W_k V4
```

将三个图分支向量映射为值向量：

```text
u_market = W_v V2
u_demand = W_v V3
u_supply = W_v V4
```

代码中默认注意力隐藏维度为：

```text
attention_dim = 32
```

### 4.3 注意力分数

三个图分支的注意力分数为：

```text
e_market = q^T k_market / sqrt(d)
e_demand = q^T k_demand / sqrt(d)
e_supply = q^T k_supply / sqrt(d)
```

其中：

```text
d = attention_dim
```

除以 `sqrt(d)` 是为了避免向量维度较大时点积值过大，导致 softmax 过于极端。

### 4.4 注意力权重

通过 softmax 得到三个分支的权重：

```text
[alpha_market, alpha_demand, alpha_supply]
= softmax([e_market, e_demand, e_supply])
```

因此：

```text
alpha_market + alpha_demand + alpha_supply = 1
```

含义为：

```text
alpha_market：当前样本下 market 图的重要性
alpha_demand：当前样本下 demand 图的重要性
alpha_supply：当前样本下 supply 图的重要性
```

### 4.5 图分支融合

融合后的图特征为：

```text
V_graph =
    alpha_market * u_market
    + alpha_demand * u_demand
    + alpha_supply * u_supply
```

最终预测特征为：

```text
V_final = concat(V1, V_graph)
```

当前默认维度为：

```text
V1: 64 维
V_graph: 32 维
V_final: 96 维
```

第一版 concat 的输入维度是：

```text
64 + 32 + 32 + 32 = 160
```

第二版注意力融合后的输入维度是：

```text
64 + 32 = 96
```

## 5. 第二版与第一版的区别

| 部分 | 第一版 | 第二版 |
|---|---|---|
| CNN 分支 | 1D CNN | 1D CNN |
| GAE 编码器 | GCN-GAE | GCN-GAE |
| 图数量 | market、demand、supply 三个图 | market、demand、supply 三个图 |
| 图分支融合 | concat(V2,V3,V4) | attention(V2,V3,V4 \| V1) |
| MLP 输入 | concat(V1,V2,V3,V4) | concat(V1,V_graph) |
| MLP 输入维度 | 160 | 96 |
| 损失函数 | 不变 | 不变 |
| 可解释性 | 较弱 | 可输出三类图权重 |

第二版不是改变 GAE 本身，而是改变 GAE 分支输出后的融合方式。

可以概括为：

```text
第一版回答：把三个图信息都给模型。
第二版回答：让模型判断当前更该相信哪个图。
```

## 6. 损失函数

第二版损失函数不改变，仍然是：

```text
L_total = L_interval + lambda * L_reconstruction
```

其中：

```text
L_interval = MSE(y_hat, y) + bound_penalty
```

`bound_penalty` 用于惩罚预测最低价高于预测最高价的情况：

```text
bound_penalty = mean(max(0, low_hat - high_hat)^2)
```

GAE 重构损失仍然是三个图重构损失的平均：

```text
L_reconstruction =
1/3 * (
    MSE(A_market_hat, A_market)
    + MSE(A_demand_hat, A_demand)
    + MSE(A_supply_hat, A_supply)
)
```

因此第二版的完整损失为：

```text
L_total =
MSE(y_hat, y)
+ bound_penalty
+ lambda * 1/3 * (
    MSE(A_market_hat, A_market)
    + MSE(A_demand_hat, A_demand)
    + MSE(A_supply_hat, A_supply)
)
```

当前代码中默认：

```text
lambda = 0.1
```

也就是训练参数：

```bash
--reconstruction-weight 0.1
```

## 7. 代码实现位置

### 7.1 配置项

模型配置位于：

```text
src/copper_prediction/model.py
```

第二版新增了两个配置项：

```python
fusion_mode: str = "concat"
branch_attention_dim: int = 32
```

其中：

```text
fusion_mode = "concat"：第一版简单拼接
fusion_mode = "branch_attention"：第二版分支注意力融合
```

### 7.2 注意力融合模块

第二版新增模块：

```python
class BranchAttentionFusion(nn.Module):
```

输入为：

```text
v1:       [batch_size, 64]
v_market: [batch_size, 32]
v_demand: [batch_size, 32]
v_supply: [batch_size, 32]
```

输出为：

```text
fused:            [batch_size, 96]
branch_attention: [batch_size, 3]
v_graph:          [batch_size, 32]
```

其中 `branch_attention` 的三列依次为：

```text
第 1 列：market_attention
第 2 列：demand_attention
第 3 列：supply_attention
```

### 7.3 主模型中的调用

主模型为：

```python
class CopperIntervalPredictor(nn.Module):
```

当：

```python
fusion_mode == "concat"
```

模型执行第一版：

```python
fused = torch.cat([v1, v2, v3, v4], dim=-1)
```

当：

```python
fusion_mode == "branch_attention"
```

模型执行第二版：

```python
fused, branch_attention, v_graph = self.branch_attention(v1, v2, v3, v4)
```

同时会在 `aux` 中返回：

```python
aux["branch_attention"]
aux["v_graph_attention"]
```

这样训练时仍然可以正常计算损失，预测或分析时可以取出注意力权重。

## 10. 注意力权重如何解释

假设某一天输出为：

```text
market_attention = 0.60
demand_attention = 0.25
supply_attention = 0.15
```

可以解释为：

```text
该日模型认为宏观市场图对铜价区间预测贡献最大。
```

如果某阶段持续出现：

```text
demand_attention 较高
```

说明模型更依赖需求端信息，例如 AI 硬件、新能源车、电网、电力设备、地产基建等资产变化。

如果某阶段持续出现：

```text
supply_attention 较高
```

说明模型更依赖供给端信息，例如矿企股票、库存、注销仓单、运费等变量变化。

后续可以把注意力权重按时间画图：

```text
x 轴：交易日期
y 轴：attention weight
三条线：market、demand、supply
```

然后观察模型在不同市场阶段的关注点是否符合经济解释。

## 11. 实验对比设计

第二版必须和第一版进行严格对比。

建议至少做两组实验：

```text
模型 A：CNN + GCN-GAE + Concat
模型 B：CNN + GCN-GAE + Branch Attention
```

控制变量：

```text
使用同一份数据
使用同样的训练集、验证集、测试集划分
使用同样的 CNN 窗口长度
使用同样的相关系数窗口
使用同样的 GAE 隐藏维度和嵌入维度
使用同样的 epoch、batch_size、learning_rate
使用同样的随机种子
```

训练命令示例：

```bash
.venv/bin/python scripts/train.py \
  --raw-dir data/raw \
  --output-dir outputs/models_concat \
  --fusion-mode concat \
  --seed 42 \
  --epochs 50
```

```bash
.venv/bin/python scripts/train.py \
  --raw-dir data/raw \
  --output-dir outputs/models_branch_attention \
  --fusion-mode branch_attention \
  --branch-attention-dim 32 \
  --seed 42 \
  --epochs 50
```

对比指标建议包括：

```text
train_loss
val_loss
test_loss
MAE
RMSE
区间覆盖率
平均区间宽度
方向准确率
```

其中区间预测任务尤其应该关注：

```text
区间覆盖率：真实 low/high 是否落在预测区间内
平均区间宽度：预测区间是否过宽
```

理想情况不是只让区间覆盖率高，因为如果预测区间无限宽，覆盖率也会很高。更合理的模型应该在覆盖率较高的同时保持区间宽度不过分扩大。

## 12. 预期结果与可能解释

如果第二版优于第一版，可以说明：

```text
market、demand、supply 三个图分支并不是在所有样本中具有固定贡献；
不同市场阶段下，分支重要性存在动态变化；
分支注意力融合能够增强模型对阶段性主导因素的刻画能力。
```

如果第二版没有明显优于第一版，可能有几种原因：

```text
训练样本数量不足，注意力模块增加参数后更难训练
三个图分支之间信息重叠较多，注意力收益不明显
当前节点选择或连边构造还不够稳定
目标变量噪声较高，分支权重难以学习出清晰结构
```

这种情况下可以继续检查：

```text
attention 是否长期接近 1/3、1/3、1/3
attention 是否长期偏向某一个分支
不同年份的 attention 是否有阶段性变化
验证集 loss 是否比训练集 loss 明显更高
```

## 13. 与第三版的关系

第二版和第三版解决的问题不同。

第二版解决的是：

```text
三个图之间，哪个图更重要？
```

第三版解决的是：

```text
每个图内部，哪些邻居节点更重要？
```

因此，推荐实施顺序为：

```text
第一版：CNN + GCN-GAE + Concat
第二版：CNN + GCN-GAE + Branch Attention
第三版：CNN + GAT-GAE + Branch Attention
```

这样论文逻辑更清楚：

```text
先建立基础模型；
再改进跨图分支融合方式；
最后改进图内部节点聚合方式。
```

## 14. 第二版一句话总结

第二版模型可以概括为：

```text
保留 CNN 与三个 GCN-GAE 分支不变，在 V2、V3、V4 之后加入由 V1 引导的分支注意力机制，使模型能够根据铜自身近期走势，动态分配 market、demand、supply 三类图信息的权重，再进行铜价区间预测。
```
